# Customer Management API

REST API quản lý khách hàng được xây dựng bằng Node.js, Express và SQL Server.

## Chức năng

API hỗ trợ các thao tác CRUD đối với khách hàng:

- Lấy danh sách khách hàng
- Lấy khách hàng theo ID
- Thêm khách hàng
- Cập nhật khách hàng
- Xóa khách hàng

## Công nghệ sử dụng

- Node.js
- Express
- SQL Server
- mssql
- JavaScript
